imd-schemas

Check IMD paid action inputs locally with draft 2020-12 JSON Schemas, a TypeScript library and a Node 20+ command-line validator.

All build dependencies are included as ordinary files. From the checkout:

npm test
node bin/imd-validate.cjs schedule.create examples/schedule-oracle.json --version schedule-1
node bin/imd-validate.cjs --refusals

Validate the action's input body. Pass the server's exact action version to detect unsupported updates. An action alone uses the frozen local snapshot.

The validator reports field errors and selected planning warnings. Successful local validation does not guarantee server admission, wallet ownership, resource availability or successful evaluation. No wallet connects and no payment is sent by this project.
